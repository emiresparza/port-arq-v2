DESARROLLO DE PROYECTO

Del criterio de diseño a una documentación coherente.

Trabajamos sobre anteproyectos, modelos, planos y definiciones existentes para llevar la arquitectura a un mayor nivel de desarrollo.

Cada decisión se revisa como parte de un sistema: distribución, geometría, materialidad, envolvente y encuentros constructivos deben responder a una misma lógica de proyecto.

01

Modelo arquitectónico

Construimos una base común para comprender el proyecto, revisar su geometría y relacionar correctamente plantas, niveles, envolvente y espacios.

El modelo no es un resultado aislado: es una herramienta para desarrollar y verificar la arquitectura.

02

Desarrollo

Profundizamos las decisiones que permiten pasar de una idea general a un proyecto definido.

Resolvemos dimensiones, materialidades, sistemas, encuentros y puntos críticos manteniendo coherencia entre la intención de diseño y su construcción.

03

Documentación

Representamos el proyecto mediante planos, láminas, detalles y especificaciones con jerarquías claras y un lenguaje gráfico consistente.

La documentación debe permitir comprender la arquitectura, revisarla y continuar su desarrollo sin interpretaciones innecesarias.

ENTREGABLES

Cada entrega debe conservar la lógica del proyecto.

No producimos modelos, planos o imágenes como piezas independientes. Cada documento debe responder a los antecedentes disponibles, a una decisión arquitectónica y a una etapa concreta del proyecto.

Zenteno
