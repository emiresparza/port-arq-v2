Arquitectura

QUINCHO SS

El proyecto se trata de un espacio cerrado e independiente que amplia las posibilidades de uso de la vivienda principal. incluye comedor, barra y una amplia zona destinada a la cocina. Diseñado para ser utilizado durante todo el año, el proyecto combina materiales de caracter industrial, acentos de color y soluciones de bajo mantenimiento. El resultado es un espacio comodo y funcional para cocinar, recibir y compartir.
