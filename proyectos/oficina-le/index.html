OFICINA LE

Habilitación de oficina gerencial para múltiples usos. Se desarrollaron espacios de trabajo, sala de reuniones con espacio de presentación, recibidor, cafetería y sala de lectura. Diseñado para facilitar el flujo de trabajo con múltiples equipos de personas. Se diseñó mobiliario especializado para los diferentes ambientes y usos, además de un trabajo de especificación de materiales e interiorismo coordinado.
